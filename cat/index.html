How to use this deck

CAT Grade 12 · Paper 2 Theory

This covers all five Paper 2 theory sections: Systems Technologies (Hardware & Software), Internet & Network Technologies, Information Management, Social Implications, and Communication Technologies.

Content is drawn from the exam and memo patterns in your project's IEB past papers (2020–2025) plus general CAT syllabus knowledge, written in my own words — not copied from the textbook, since that still isn't sourced. Once you upload it, treat this deck as a second pass to refine against.

Paper numbering quirk In 2020, the theory exam was Paper 1 and the practical exam was Paper 2. From 2021 onward, IEB swapped this: Paper 2 is theory and Paper 1 is practical. This deck follows the 2021+ convention and pulls examples from both eras — worth knowing if you're cross-referencing your 2020 papers by number.
How marks work here Paper 2 gives roughly a mark per fact, and expects full sentences — one-word answers often don't score. "Give TWO advantages" means the marker wants two distinct, separately-stated facts, not one idea phrased twice.

Input Devices

Section A · Systems Technologies

Standard & specialised input

  • Keyboard / mouse — standard text and pointer input.
  • Scanner — converts a physical document/image into a digital file.
  • Webcam / microphone — capture video/audio for calls, recording, or streaming.
  • Touchscreen — combines input and output; the display itself detects touch.
  • Barcode / QR scanner — reads coded data for quick lookup (retail, logistics).
  • Biometric scanner — fingerprint or facial recognition for identity verification.
  • Graphics tablet — a pressure-sensitive surface for drawing/design input.

Assistive input devices accessibility

  • Braille keyboard — a keyboard with raised dots, letting visually impaired users type in Braille.
  • Switch access device — a simplified button/switch input for users with limited mobility.
  • Eye-tracking device — lets a user control a cursor using eye movement.
  • Voice recognition software paired with a microphone — converts speech into text or commands (also counts as assistive software).
Exam patternA 2023 Question 3 asked candidates to name a Braille keyboard and explain that it lets visually impaired users enter data in Braille — any accessibility-hardware question expects you to link the device directly to the disability it assists.

Visual & audio output

  • Monitor — displays visual output; refresh rate is measured in Hz.
  • Projector — casts a large-scale image onto a screen or wall.
  • Speakers / headphones — produce audio output.
  • Braille embosser/printer — assistive output device that prints raised-dot Braille text.

Storage Devices & Memory

Section A · Systems Technologies

RAM vs ROM

RAMROM
VolatilityVolatile — cleared when power is offNon-volatile — retains data without power
PurposeTemporary working memory while programs runPermanently stores startup instructions (e.g. BIOS)
Can it be edited?Yes, constantly, during normal useNot normally — fixed at manufacture

HDD vs SSD

HDDSSD
How it stores dataSpinning magnetic disk, moving read/write headFlash memory chips, no moving parts
SpeedSlowerMuch faster read/write
DurabilityMore prone to physical/mechanical failureMore durable, silent, less heat
Cost per GBCheaperMore expensive, though the gap is narrowing

Other storage

  • Optical media (CD/DVD/Blu-ray) — laser-read discs, largely superseded by flash/cloud storage.
  • Flash/USB drive — small, portable solid-state storage.
  • Cloud storage — data stored on remote servers and accessed over the Internet.
  • Cache memory — very fast, small-capacity memory sitting between the CPU and RAM, storing frequently used data.
Memory hierarchySpeed and cost per GB both increase as you move from secondary storage → RAM → cache → CPU registers. Capacity moves the opposite way.

Processing, Motherboard & Ports

Section A · Systems Technologies

Core components

  • CPU — executes instructions and performs calculations; often called the "brain" of the computer. Speed measured in GHz; more cores allow more tasks to run in parallel.
  • Motherboard — the main circuit board connecting the CPU, RAM, storage, and other components.
  • Power supply unit (PSU) — converts AC power from the wall outlet into the DC power the components need.
  • Graphics card (GPU) — processes and renders images/video, taking that load off the CPU.
  • Sound card — generates and processes audio; converts analogue signals (e.g. microphone input) to digital and back.
  • Cooling (heat sink/fan) — removes heat generated by the CPU/GPU to prevent overheating.

Hardware ID roundup real past-paper items

External CD/DVD/Blu-ray drive (burner)Reads from and writes data to optical discs.

Exam patternSection B Question 3 (System Technologies) has consistently shown a photo of a component and asked for its name plus main function, one mark each — across 2020–2024. Practice naming components from a photo, not just from a definition.

Ports & connectivity

  • USB — general-purpose port for peripherals and storage.
  • HDMI — carries digital video and audio to a display.
  • Ethernet port — connects a device to a wired network via a network/UTP cable.
  • Bluetooth / Wi-Fi adapter — enables wireless connection to nearby devices or a network.

  • Provides the user interface (desktop, windows, icons).

Buying, Upgrading & Troubleshooting

Section A · Systems Technologies

Buying considerations

  • Purpose — what the device will mainly be used for.
  • Budget — what you can afford, balanced against needs.
  • Specifications — RAM, storage, processor speed suited to the intended use.
  • Portability — whether you need to move it around.
  • After-sales support/warranty — protection if something goes wrong.

Common causes of hardware failure

  • Power failure / load shedding
  • Power surges
  • Hardware failure / disk crash
  • Malware
  • Poor maintenance / overheating
Exam pattern"Give TWO reasons a computer might fail" draws directly from this list across multiple years — state the cause, not a vague symptom.

Basic troubleshooting steps

  • Check cables and connections are secure.
  • Restart the device.
  • Update or reinstall the device driver.
  • Run an antivirus/malware scan.
  • Check for available software/OS updates.

Emerging Technologies

Section A · Systems Technologies

Current exam-relevant technologies

  • Internet of Things (IoT) — everyday devices connected to the Internet, able to send/receive data and be sensed or controlled remotely without direct human interaction.
  • Wearable device — a small computer worn on the body, e.g. a smartwatch or fitness tracker.
  • Cloud computing — storing/accessing data or programs over the Internet rather than locally.
  • Grid computing — combining the processing power of multiple networked computers to solve one large problem.
  • 3D printing — building a physical object layer-by-layer from a digital model.
  • Virtual/digital assistant vs chatbot — assistants adapt dynamically to a conversation; chatbots follow a more limited, rule-based script and struggle with interrupted conversations.
  • Biometrics — identifying a person by a unique physical trait (fingerprint, face, iris).
Exam patternThe Section C integrated scenario (Questions 8–9) regularly leans on emerging tech — IoT and grid computing definitions have both appeared as scenario-based recall questions.

Internet, WWW & Browsers

Section B · Internet & Network Technologies

Core distinctions

  • Internet — the physical global network of interconnected computers.
  • World Wide Web (WWW) — a service that runs on the Internet: the collection of linked webpages accessed through a browser.
  • Website — a collection of related webpages.
  • Webpage — a single document within a website.
  • Browser — software used to access and display webpages.
  • Search engine — a program/website that helps you find webpages using keywords.
Common mistakeInternet vs WWW vs website is one of the most consistently penalised mix-ups on this paper. Internet = the network. WWW = the service. Website = one collection of pages on that service. Keep them straight.
Common mistakeUpload vs download direction gets flipped under pressure. Upload = sending data from your device to a server/the Internet. Download = receiving data from a server/the Internet onto your device.

Connecting to the Internet

Section B · Internet & Network Technologies

Key terms

  • ISP — Internet Service Provider, a company that provides Internet access.
  • Bandwidth — the amount of data that can be transferred over a connection in a given time period.
  • Broadband — a high-speed, high-bandwidth, always-on connection.

Data package terminology

TermMeaning

Exam patternA 2021 Question 4 asked candidates to identify a WLAN connection from a scenario and explain how a router functions — know that a router's core job is directing/connecting traffic between different devices and networks.

Network & Data Security

Section B · Internet & Network Technologies

Securing a network

  • Firewall — monitors and controls incoming/outgoing traffic based on security rules.
  • Passwords/encryption — restrict who can join or read traffic on the network.
  • Restricted/whitelisted access — only approved users or IP addresses can connect.
  • Two-factor authentication — a second, independent verification step beyond a password.
  • Biometric access — fingerprint/facial recognition, harder to fake or steal than a password.

Strong password practice

  • Mix upper- and lower-case letters.
  • Include numbers and special characters.
  • Avoid easily guessed personal information (name, ID number).
  • Make it longer than 8 characters.

Surface, Deep & Dark Web

Section B · Internet & Network Technologies
  • Surface web — indexed by standard search engines, freely accessible.
  • Deep web — not indexed by standard search engines (private databases, paid content) but still legal to access.
  • Dark web — a hidden part of the Internet requiring special software, associated with anonymity and often illegal activity.

Chatbots vs virtual assistants

Data, Information & Metadata

Section C · Information Management
  • Data — raw, unprocessed facts and figures.
  • Information — data that's been processed and organised into a meaningful, useful form.
  • Metadata — data that describes other data, e.g. a file's author, size, or date created.
The syllabus also frames information handling as a cycle — roughly plan/question, find, evaluate, process, and present/acknowledge sources. I don't have your textbook's exact wording or step names for this yet, so treat this outline as a placeholder until we can check it against the book directly.

Online Forms & Validation

Section C · Information Management
  • Required field — usually marked with an asterisk (*); must be completed before submission.
  • Validation/format restriction — e.g. forcing a date field into a specific format, so the data entered is consistent and usable by the system.
  • CAPTCHA — confirms the user is human, not an automated bot.
  • Closed questions (fixed set of answers, e.g. yes/no) are preferred in questionnaires because they're quicker and easier to capture and analyse than open-ended answers.
Exam pattern"Give TWO restrictions to ensure a date is entered correctly" is a recurring Question 5 style — think in terms of format enforcement (e.g. forcing dd/mm/yyyy), not just "make it compulsory".

Databases & Reports

Section C · Information Management
  • Database — stores, organises, and manages large amounts of related data so it can be searched, sorted, and reported on.
  • Database report — presents selected, organised data in a readable, formatted way, often grouped or summarised.
  • Grouping records together (e.g. by learner, by category) makes it possible to show totals/counts per group — a summary function like Count is placed in the group header/footer section of the report, not the detail section.

Evaluating Sources & Big Data

Section C · Information Management

Big data

Big data — extremely large, complex data sets analysed by computer to reveal patterns and trends. Benefits for a business include better decision-making, spotting customer trends, and more targeted marketing.

Evaluating a source

  • Check the author's credentials.
  • Check the publication date — is it current?
  • Check the domain/publisher for credibility.
  • Cross-check the claim against other reputable sources.
ReferencingA bibliography acknowledges the sources used and lets a reader locate the original material — and helps you avoid plagiarism (presenting someone else's work as your own).

Security & Cybercrime

Section D · Social Implications
  • Social engineering — manipulating a person into revealing confidential/sensitive information for fraudulent purposes.
  • Reverse social engineering — the attacker engineers a situation so the victim contacts them for help, then exploits that trust to gain access or information.
  • Phishing — fake emails/websites that look legitimate, tricking users into giving up personal/financial information.
Exam patternA 2024 Question 6 asked for two scenarios of reverse social engineering — think "attacker creates the problem, then poses as the helpful solution" (a fake vendor call, a fake job interview, sabotage followed by a fake fix).

Privacy & Digital Footprint

Section D · Social Implications
  • Digital footprint — the trail of data a person leaves behind through online activity.
  • Passive footprint — data collected without the user directly acting, e.g. browsing logs.
  • Active footprint — data the user deliberately shares, e.g. a social media post.
Discussion-style question"Does the Internet offer users privacy?" has appeared as an agree/disagree question. Either position can score, as long as you back it with two specific, distinct reasons.

Health, Ergonomics & Green Computing

Section D · Social Implications

Health risks of heavy device use

  • Eye strain from prolonged screen exposure (including HEV light).
  • Headaches, sleep disturbance, decreased attention span.
  • Repetitive strain injury from poor posture/positioning.
  • Behavioural addiction and isolation from excessive use.

Ergonomics

Recommended precautions: take regular breaks, use an adjustable/ergonomically designed chair, keyboard, and monitor height.

Green computing

Green computing — using technology in an environmentally responsible, energy-efficient way, e.g. recycling e-waste, using energy-saving settings, or buying energy-efficient hardware.

Businesses saving resourcesSaving paper (electronic documents instead of printing), saving communication cost (email/VoIP instead of calls), and saving time (faster typing/calculations) — a recurring three-part answer pattern.

Digital Divide, Addiction & Society

Section D · Social Implications
  • Digital divide — the gap between people with easy access to computers/the Internet and those without.
  • Internet addiction — commonly linked to excessive social media use or online gaming.
  • Technology's effect on employees can include job losses from automation, but also new roles and flexible/remote work.

Accessibility & inclusion

A 2025 scenario question asked for hardware and software technologies that assist physically disabled users. Hardware: adapted keyboards/switches, eye-tracking devices, Braille displays. Software: voice recognition, screen readers, on-screen/predictive keyboards.

Blogs, Wikis & Social Media

Section E · Communication Technologies
  • Blog — a regularly updated, informally written personal or business webpage.
  • Wiki — a website that lets multiple users collaboratively edit its content.
Keeping a site engagingUpdate content regularly, use an attractive/consistent design, respond to feedback/comments, and keep text concise and error-free.

Web Conferencing & VoIP

Section E · Communication Technologies
  • Webinar — a live, interactive seminar/meeting conducted over the Internet, usually with video.
  • VoIP — Voice over Internet Protocol; making voice calls over the Internet instead of a traditional phone line.
  • Video call advantages: you can see gestures/body language, multiple participants can join, and it feels closer to an in-person conversation.
  • Common tools named in past papers: Zoom, Microsoft Teams, Google Meet/Hangouts, Cisco WebEx, GoToMeeting, TeamViewer.

RSS, Podcasts & QR Codes

Section E · Communication Technologies
  • RSS — automatically delivers updated content to subscribers without them checking the site manually.
  • Podcasting — publishing audio/video files online for users to download or stream.
  • QR code — a two-dimensional barcode storing more data than a normal barcode; needs a device with a camera and appropriate software to read it.
  • Ways to notify people new content is available: SMS, a blog post, an RSS feed, email, or an app notification.
Common mistakeSharing large video/audio files by email runs into bandwidth limits, spam filters, and slow upload/download — that's why podcasting/streaming links are preferred over attachments.

Netiquette

Section E · Communication Technologies

Netiquette — the accepted rules of polite, respectful behaviour when communicating online.

Synchronous communication happens in real time (e.g. a video call). Asynchronous communication doesn't need both people present at once (e.g. email).

Paper 1 Overview & Exam Setup

Section F · Paper 1 · Practical (180 marks, 3 hours)

Paper 1 is the practical paper: five sections, generally Word Processing, Spreadsheets, Databases, Web Design (HTML), and an Integrated Scenario question that mixes general theory with practical application. Content here is drawn from the exam instructions, questions, and memos in your project's IEB past papers (2021–2025), written in my own words.

Paper numbering quirk Same swap as noted on the Theory deck: from 2021 onward, Paper 1 is practical and Paper 2 is theory. In 2020 it ran the other way round — check the year before you reference a past paper by number.

Fixed exam-setup rules

  • Rename your Data Files folder to your exam number before starting, e.g. Data Files becomes 1234567890.
  • Use functions/formulas to calculate answers unless an instruction says otherwise — typed-in values instead of a formula usually lose the mark.
  • Default word-processing setup unless told otherwise: measuring units in centimetres, language English (South Africa), page size A4, margins 2.54 cm.
  • The Developer Tab must be enabled in Word and Excel before you start (needed for content controls, macros).
  • HTML must be coded in a plain text editor — Notepad, Notepad++, or WordPad. Microsoft Word may not be used to write HTML.
  • Save regularly, and only work inside the folder named for that question — don't rename or move files outside the structure given.
Partial-mark safety netIf a formula or feature genuinely won't work, use the Student_Screenshots document: note the question number, paste a screenshot of the problem, and add a short explanation. This can earn part marks even without a working solution.

Word Processing Toolkit

Section F · Paper 1 · Word Processing

Styles & Table of Contents

  • An automatic Table of Contents only pulls in text formatted with a recognised Heading style (or a custom style you've told Word to include). If a heading was typed in bold instead of styled, it won't appear in the TOC — you have to apply the style, not just make it look right.
  • You can create a custom style (e.g. name it "SectionHeader") with specific font size, colour, and formatting, then apply it consistently so a one-level TOC can reference it.
  • Multilevel lists need the correct outline level applied to each line, not just visually indented text.
Common mistakeBuilding a TOC before applying heading styles, or applying direct formatting (bold/size) instead of a style, are the two most common reasons a TOC comes out empty.

Track changes, comments & footnotes

  • Track Changes records edits so others can review, accept, or reject them without the original work being lost.
  • Comments let you leave notes/suggestions for the document owner without editing the text itself; a comment can be linked to specific highlighted text.
  • Track changes markup can be set to show only insertions and deletions (hiding formatting changes) for a cleaner review view.
  • A footnote gives extra information or a source reference at the bottom of the page, linked to a small number/symbol in the body text; an endnote does the same but collects references at the end of the document. Word can convert a footnote to an endnote and back.

Layout & formatting features

FeatureWhat it's for
Section breakSplits a document into parts that can each have independent formatting/page numbering (e.g. different headers on different sections).
Hanging indentFirst line of a paragraph sits at the margin; all following lines are indented (common in reference lists).
Orphan/Widow controlKeeps paragraph lines together so a single line isn't left stranded at the top/bottom of a page.
BookmarkMarks a location in a document so it can be jumped to or linked to directly.
HyperlinkClickable link to a web address, email, or bookmark within the document.
Different odd/even header or footerLets facing pages show different header/footer content (e.g. file name only on odd pages).
Exam patternParagraph/line spacing questions ask for exact values (e.g. "12 pt before and after," "line spacing Multiple 1.75") — the mark is for the precise number, not just "increased spacing."

Mail merge

  • Mail merge links a template document to a data source (commonly a .csv file) so personalised copies can be produced for each record.
  • A typical mail-merge task: insert the required fields into the template, sort the data source by a chosen field, then complete the merge into a single combined output document.

Metadata & saving formats

  • Metadata in a word-processing document includes things like author, subject, company, dates created/modified, size, page/word count, title, tags, comments, template, status, and categories.
  • Ways to make a document usable by someone without the same software/version: save in an earlier file version, save as PDF or RTF, or save as a plain text file.

Accessibility & document design

Readability in this context means how well someone experiences the document — including whether a screen-reader user or visually impaired person can follow it. Word features that help with collaboration and readability: Track Changes, Comments, and shared/collaboration tools (co-authoring). Improving readability for a visually impaired reader can include increasing line spacing or decreasing dense text blocks.

Excel — Core Formulas

Section F · Paper 1 · Spreadsheets

Formula vs function

A function is built into the application (e.g. SUM, IF). A formula is a calculation you build yourself using cell references, operators, and (optionally) functions combined together.

Conditional counting & summing

NeedFormula pattern
Count cells matching one condition=COUNTIF(range,"criteria")
Count empty cells=COUNTBLANK(range) or =COUNTIF(range,"")
Count non-empty cells=COUNTA(range)
Count matching two or more conditions=COUNTIFS(range1,"criteria1",range2,"criteria2")
Sum cells matching one condition=SUMIF(range,"criteria",sum_range)
Sum cells matching two or more conditions=SUMIFS(sum_range,range1,"criteria1",range2,"criteria2")
Common mistakeSUMIF/SUMIFS add values together — they can't tell you how many records match. If a question asks "how many," that's a COUNTIF/COUNTIFS job, even if the data looks numeric.

Ranking, extremes & rounding

NeedFormula pattern
Nth smallest value=SMALL(range,n)
Nth largest value=LARGE(range,n)
Round down to a set number of decimals=ROUNDDOWN(number,digits) — e.g. =ROUNDDOWN(4.87,1) → 4.8
Round up to a set number of decimals=ROUNDUP(number,digits) — e.g. =ROUNDUP(2.3,0) → 3
Ordinary rounding=ROUND(number,digits)

Logical (IF-family) formulas

NeedFormula pattern
Single condition=IF(condition,value_if_true,value_if_false)
Nested nested conditions (three or more outcomes)=IF(cond1,result1,IF(cond2,result2,result3))
Cleaner multi-outcome alternative=IFS(cond1,result1,cond2,result2,cond3,result3)
Exam patternA three-tier classification (e.g. "High/Medium/Low") is commonly marked correct however it's built — nested IF or IFS both score, as long as the thresholds and order are right.

Excel — Lookup, Text & Date Functions

Section F · Paper 1 · Spreadsheets

Looking up values

NeedFormula pattern
Look up a value down a column=VLOOKUP(lookup_value,table_range,col_index,FALSE)
Look up a value across a row=HLOOKUP(lookup_value,table_range,row_index,FALSE)
Modern lookup with built-in "not found" handling=XLOOKUP(lookup_value,lookup_array,return_array,"NotFound",0)
Combine lookup with a dynamic column/row positionNest MATCH() inside VLOOKUP/HLOOKUP as the column or row index.
FALSE / exact matchThe last argument (FALSE, or 0 in XLOOKUP) tells Excel to find an exact match only — leaving it out or using TRUE risks matching the wrong, "closest" row.

Text functions

NeedFormula pattern
Characters from the left=LEFT(text,num_chars)
Characters from the right=RIGHT(text,num_chars)
Characters from the middle=MID(text,start_num,num_chars)
Position of a character (e.g. a space or @)=FIND("character",text,start_num)
Join text and cell values together=CONCATENATE(text1,text2,...) or the shorthand & operator, e.g. =A3&LEFT(F3,FIND("@",F3,1)-1)
Exam patternExtracting part of a value (like a floor number from a room code, or a username from an email) is almost always a LEFT/RIGHT/MID combined with FIND to locate the split point dynamically — not a fixed number that only works for one row.

Date & random functions

NeedFormula pattern
Current date=TODAY() (or =NOW() for date and time)
Random whole number in a range=RANDBETWEEN(bottom,top)

Wildcards in criteria

A wildcard (e.g. * or a partial string like "Smi*") is used in COUNTIF/SUMIF/query criteria to match based on a partial match, rather than requiring an exact match — e.g. returning every record starting with "Smi" regardless of what follows.

Excel — Data Tools & Charts

Section F · Paper 1 · Spreadsheets

Formatting & layout tools

  • Merge & Center — combines selected cells into one and centres the content, commonly used for titles across a row.
  • Freeze Panes — keeps chosen rows/columns visible on screen while scrolling through the rest of the sheet.
  • Data Validation — restricts what can be typed into a cell (e.g. whole numbers only, greater than 0) and can show a custom input message or error alert.
  • Conditional Formatting — automatically changes a cell's appearance based on its value meeting a rule.
  • Named ranges, tab colours, and row height/column width are all common small-mark formatting instructions — read the exact value asked for (e.g. "row height 42.00") rather than eyeballing it.

Sorting, filtering & validation

  • Data can be sorted or filtered on more than one column at once (e.g. sort by surname, then filter to exclude certain categories).
  • Data Validation rules are commonly asked for percentage/mark fields (e.g. restrict entries to between 0 and 100) to stop invalid data being entered in the first place.

Grouping, subtotals & outlines

The Subtotal tool automatically inserts summary rows (e.g. a Count or Sum) at each change in a chosen column, and can group/collapse the detail rows into an outline view. It can also insert a page break between each group automatically.

Charts

  • Choose a chart type that fits the comparison being made — a clustered column chart for comparing categories is a frequent choice.
  • Chart elements commonly asked for: chart title text, axis minimum/maximum bounds, major unit spacing on an axis, and a border around the title.
  • Series data ranges are sometimes non-contiguous (multiple selected blocks) — hold Ctrl while selecting each range for the chart source.

Import & export between applications

  • To move spreadsheet data into a database application, use Import/Get External Data rather than retyping it.
  • Exporting is the general term for transferring data from one application (e.g. a database) into another format, without simply copying and pasting.

Keys & imports

  • A primary key uniquely identifies each record; a table should only have one, and it's often necessary to remove an incorrectly-assigned one before setting the correct field.
  • Records can be imported into an existing table directly from an Excel file or a text/CSV file, rather than retyped.

Table & export tasks

Common small-mark table tasks: change alternate row background colour, change a field's data length, and export a table's contents to a CSV file with field names included on the first row.

Database — Queries, Forms & Reports

Section F · Paper 1 · Database (Access)

Query criteria patterns

  • AND logic (both conditions true) — put both criteria in the same criteria row under their respective fields.
  • OR logic (either condition true) — put the criteria in separate rows (the query grid's "or" row), or use OR directly in one field's criteria.
  • Wildcard/partial match — e.g. a country field "contains south" uses a wildcard pattern rather than an exact match.
  • Totals query — groups records (e.g. by country) and aggregates a numeric field (e.g. sums experience ratings) per group.
  • Sorting a query result and choosing which fields are visible are both usually separate, explicitly marked steps — don't skip setting the sort order even if the question only emphasises the fields.
Common mistakeOnly showing the fields the question names as output is not automatically "AND" or "OR" — the difference is entirely about which row the criteria sit in in the query design grid.

Forms

  • A form can be built from more than one related table at once, and grouped by the "parent" table so related child records display together.
  • A text box control can be converted into a combo box that looks up values from another table, matching the same behaviour as a table-level lookup field.
  • A command button can be added to a form (e.g. in the footer) to trigger an action, such as adding a new record, with a custom caption.
  • Header/label text and its formatting (e.g. forcing it onto one line) are common small-mark form-design tasks.

Reports

  • A report is typically built from selected fields across one or more tables, then grouped by a chosen field so related records are clustered together.
  • A text box can be inserted into a group footer to automatically count or total the records within that group (e.g. number of delegates per organisation).
  • Labels (like an exam number) are commonly required in the report header, as a separate step from the grouping/totalling tasks.
Exam patternQuery, form, and report questions are usually marked in discrete steps (create the object → apply the specific property → save) — partially completing an object without saving it under the exact requested name typically loses marks even if the logic was right.

Applications recap

Typical business use-cases the exam expects you to be able to state: spreadsheet for calculations/invoices/financial statements; word processing for correspondence/contracts/minutes; database for employee/stock/supplier data; email for communication; web browser for research. Marks go to the specific use given, not just naming the application.

Exam patternHTML section instructions are usually one small, self-contained edit per numbered item (1–2 marks each). Make each change, save, and re-open the file in a browser to check it visually before moving to the next instruction — a missing closing tag can silently break everything below it.

Debugging checklist

  • Every opening tag needs a matching closing tag, except explicitly self-closing tags like <BR />, <HR />, and <IMG />.
  • Attribute values should be inside quotation marks, e.g. WIDTH="200".
  • Tags can be uppercase or lowercase in HTML, but the exam's own tag sheet uses uppercase — matching that convention keeps your code easy for you (and a marker) to check against it.
  • If a page "looks wrong" after an edit, check the tag just before your change first — an unclosed tag anywhere above will often cascade and break everything that follows.
